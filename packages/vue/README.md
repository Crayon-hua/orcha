# @ihxy/orcha-vue

Orcha — Vue Flow canvas adapter. Hosts should **not** install `@vue-flow/*`; this package depends on them and re-exports `Handle`, `Position`, `useVueFlow`.

```ts
import { Handle, Position, WorkflowCanvas } from '@ihxy/orcha-vue'
```

Install with the editor:

```bash
pnpm add @ihxy/orcha-editor vue
```
